# 출고내역 정리기

> **쓰기 전에**
> 1. 넣은 파일은 브라우저를 떠나지 않습니다. F12 → Network 탭을 열어 둔 채 파일을 넣어 보면, 파일을 보내는 요청이 하나도 없는 것을 확인할 수 있습니다.
> 2. 이 정리기가 못 하는 것: 정답과 대조했을 때 놓친 것은 없었습니다. 다만 빈칸(유통기한·수량), 튀는 수량(600·2400·8000, 음수, 0), 품목코드↔제품번호 불일치는 진짜 값을 모르기 때문에 고치지 않고 `_표시` 칸에 까닭만 적습니다. 이 파일에서는 16줄이고, 직접 확인해야 합니다.
> 3. 처방을 바꾸려면 코드가 아니라 `rules/` 의 파일(예: `rules/출고내역.json`)을 고칩니다.

출고내역 엑셀을 끌어다 놓으면, `rules/` 의 처방대로 정리한 **정리본**과 **바꾼 기록**을 내려받을 수 있는 페이지입니다.

## 쓰는 법

1. 페이지를 열고 엑셀 파일(.xlsx · .xls · .csv)을 끌어다 놓습니다.
2. 줄 수와 칸 수, 그리고 파일 이름에 맞는 처방(`rules/<파일 이름>.json`)과 그 이유가 나옵니다.
   맞는 처방이 없으면 «이 파일에 맞는 처방이 없습니다»가 뜨고, 처방 파일을 직접 고를 수 있습니다.
3. «규칙대로 정리»를 누르면 행 전후 · 지운 행 · 고친 값 · 표시한 행 · «두 번 돌려도 같은 결과»가 나옵니다.
4. 정리본과 바꾼 기록을 엑셀로 내려받습니다.
5. (선택) «정답과 대조»에서 내 컴퓨터의 정답 파일을 고르면 일치하는 행과 어긋난 칸을 보여 줍니다. 정답 파일은 사이트에 올라가지 않습니다.

## 들어 있는 것

| 파일 | 하는 일 |
|---|---|
| `index.html` · `style.css` · `app.js` | 화면 |
| `clean.js` | 처방 파일을 읽어 정리하는 계산 (처방 내용은 코드에 없음) |
| `lib/xlsx.full.min.js` | 엑셀 읽기·쓰기 — SheetJS Community Edition 0.20.3, Apache-2.0 (`lib/SheetJS-LICENSE.txt`) |
| `rules/출고내역.json` | 처방. 처방마다 이유(`why`)와 정한 사람(`owner`) |
| `data/출고내역.xlsx` | 시험용으로 지어낸 출고내역 (실제 거래처·개인정보 없음) |

## 직접 띄워 보기

이 폴더에서 `python -m http.server 8000` 을 실행하고 http://127.0.0.1:8000/ 을 엽니다.
`index.html` 을 파일로 바로 열어도 되지만, 그때는 브라우저가 처방 자동 읽기를 막으므로 처방 파일을 직접 골라야 합니다.
